# docs

| 파일 | 내용 |
|---|---|
| `assumptions.md` | 전제 검증 9종 결과 + 부수 발견 (8/9~10). 발표 논리를 "시간·이유·가정" 3축으로 교체한 근거 |
| `demo-scenarios.md` | **시연 페르소나와 `as_of` 고정값** (실측). 발표일 마감 절벽 경고 포함 |
| `review-prompt.md` | 정책 JSON 원문 대조 검수용 프롬프트 (30~40건 검수에 재사용) |
| `plan.md` | **기획서** — 문제 정의 · 차별화 3축 · 설계 원칙 · 구현 현황 · 한계 |
| `presentation.md` | **발표 대본 · 시연 촬영 순서 · Q&A 방어** (예상 질문 12개 + 실측 근거) |

## 읽는 순서

- **정책을 검수한다** → `review-prompt.md`
- **시연을 준비한다** → `demo-scenarios.md` (⚠️ `as_of` 고정 없이는 청년 페르소나 화면이 빈다)
- **왜 이렇게 설계했는지 알고 싶다** → `assumptions.md`

> 판정 규칙·스키마의 정본은 `packages/schema/` 이고, 팀 규칙은 루트 `CLAUDE.md` 다.
> 이 폴더는 그 결정에 이르게 된 근거와 운영 문서를 둔다.
